# iSofton Software Solutions

Marketing site for iSofton — an AI-driven software studio.

## Run locally

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Pages

- `/` Home
- `/services` and `/services/[slug]`
- `/work`
- `/engagement`
- `/about`
- `/contact`
- `/faq`
- `/privacy` `/terms`
